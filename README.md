# Rescripto

Completely free, fully offline & local AI text rewrite app.
100% on-device, zero data leaves the phone.

## Features

- AI text rewriting with selectable tones, intensity, length and multiple variants
- Fully on-device: llama.cpp (GGUF) for rewriting, whisper.cpp for voice dictation
- Voice input / dictation via the microphone (audio never leaves the device)
- Offline model download manager, local history, and sharing
- No accounts, no API keys, no tracking
